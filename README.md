# IPL-Match-Analytics-Dashboard
# 🏏 IPL Match Analytics Dashboard (2008–2026)

## 📌 Overview
This project analyzes IPL match data from 2008 to 2026 using Tableau and Microsoft Excel.

## 📊 Dashboard 1 - Tournament Overview
- Total Matches
- Total Runs
- Total Wickets
- Total Sixes
- Total Fours
- Total Seasons
- Runs by Season
- Matches by Season
- Top Teams by Runs
- Toss Winner Distribution

## 📊 Dashboard 2 - Player & Venue Analytics
- Top Batters
- Top Bowlers by Wickets
- Player of the Match
- Boundary Analysis
- Match by Venue
- Venue-wise Total Runs

## 🛠 Tools Used
- Tableau
- Microsoft Excel

## 📂 Dataset
- IPL Matches Dataset
- IPL Ball-by-Ball Dataset
